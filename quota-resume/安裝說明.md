# 安裝與分享

## 給收到分享包的人

1. 安裝並登入支援本機外掛與同任務排程的 Codex 桌面版。
2. 完整解壓 ZIP。不要只取出 `SKILL.md`；保留 `.codex-plugin`、`skills` 等資料夾。
3. 將解壓後的 `quota-resume` 資料夾交給 Codex，輸入：

   > 請將這個 quota-resume 資料夾安裝成我的 Codex 個人外掛。請使用本機外掛安裝流程，保留既有市集與外掛設定，驗證安裝成功；先不要替任何任務啟用自動接續。

4. 等 Codex 確認安裝成功後，在要接續工作的任務中輸入：

   > 使用 $quota-resume，替這個任務啟用額度恢復後自動接續，完成原本工作後停止。

5. 確認 App 顯示排程已啟用。請在額度耗盡前完成設定，並讓電腦、網路與 App 保持運作。

若 Codex 找不到本機安裝命令或排程工具，請先確認該版本是否提供這些功能；不要把「檔案已複製」當成「外掛安裝／排程啟用成功」。使用者無須複製分享者的帳戶檔案、金鑰、設定或排程。

## 停止

在原任務輸入「使用 $quota-resume 停止這個任務的自動接續」，或直接在 App 排程頁面停用。卸載外掛前也要先停用既有排程；只刪除資料夾不保證停止。

## 分享內容

- `.codex-plugin/plugin.json`：外掛定義。
- `skills/quota-resume/`：技能、排程文字範本與額度判斷腳本。
- `tests/`：16 項本地額度判斷測試，Python 標準函式庫即可執行。
- `README.md`、本說明與 `驗證結果.md`：用法、安裝與已知限制。

整份分享包可放在收件者自己的目錄；程式與測試不依賴分享者的磁碟路徑。本包不附帶任何已啟用的排程，也不會單靠解壓縮就開始工作。
