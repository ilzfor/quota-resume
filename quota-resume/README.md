# 額度恢復接續（quota-resume）

這是 Codex 桌面版的原生排程外掛。對需要長時間工作的任務，預先設定每 5 分鐘一次的同任務接續排程。用量恢復、且排程能正常執行時，接續原對話的未完成工作；完成或要求停止時停用。

## 安裝

將收到的 ZIP 完整解壓，保留整個 `quota-resume` 資料夾（包含 `.codex-plugin`）。把這個資料夾拖入 Codex 對話，或在 Codex 開啟它，再輸入：

> 請將這個 quota-resume 資料夾安裝成我的 Codex 個人外掛。請使用本機外掛安裝流程，保留既有市集與外掛設定，驗證安裝成功；先不要替任何任務啟用自動接續。

詳細步驟請看 [安裝說明](安裝說明.md)。安裝完成後，在需要工作的任務選用此外掛；若既有對話未載入新技能，可開新對話使用。

## 使用

安裝後，開啟需要繼續工作的任務，在對話輸入：

> 使用 $quota-resume，替這個任務啟用額度恢復後自動接續，完成原本工作後停止。

可以補充明確的完成條件，例如「全部修改完成且必要測試通過」。請在額度耗盡前啟用，因為額度完全耗盡時模型可能無法替你設定排程。

查看：`使用 $quota-resume 查看這個任務的自動接續狀態。`

停止：`使用 $quota-resume 停止這個任務的自動接續。`

額度已耗盡而無法送出指令時，可直接在 App 的排程管理畫面停用。停用只阻止後續排程，不會回滾工作或中斷已執行的動作。卸載外掛前先停用既有排程；卸載不保證刪除排程。

## 實際限制

- 必須讓電腦保持開機、連線且 Codex App 運行；外掛不會喚醒休眠的電腦。
- 每 5 分鐘是排程嘗試頻率，不是恢復時間的保證。恢復後是否成功喚醒，仍受排程器、登入、額度與服務狀態影響。
- 無法攔截或解除五小時／每週額度限制。不是零 token 背景監控器；成功執行的排程檢查與工作可能消耗額度。
- 使用原任務上下文，但不操作 `/goal` 暫停按鈕；不保證恢復 Goal 模式的 UI 狀態。
- 不變更模型、帳戶、權限或收費設定，不使用重設券。不會自動對所有任務啟用。
- 官方文件確認同對話排程、分鐘頻率和技能建立排程；未確認額度耗盡時是否自動略過／暫停排程。真實耗盡到恢復的完整流程仍需實測。如果 App 自動暫停失敗排程，必須重新啟用。

## 原始碼與驗證

`skills/quota-resume/SKILL.md` 負責啟用、查看、停用及範圍控制。`references/heartbeat-prompt.md` 提供保存到原生排程的完整工作規則。`scripts/quota_status.py` 是純本地、唯讀的額度 JSON 判斷器，不是排程器；對五小時／每週額度、未知資料和多 bucket 提供保守結果。

原生排程只透過 Codex 的 automation_update 工具建立；外掛不直接寫入排程 TOML 或資料庫。

此分享包包含 16 項額度判斷測試。若電腦有 Python 3，可在本資料夾執行 `python -m unittest discover -s tests -v`。詳細驗證範圍見 [驗證結果](驗證結果.md)。

參考：[官方同對話排程文件](https://learn.chatgpt.com/docs/automations#schedule-a-task-inside-a-chat)、[官方額度介面](https://learn.chatgpt.com/docs/app-server)。
